## Game Overview
This is an object oriented game. 
Use lasers to shoot down rocks.
Lose all health or 10 rocks out-of-bounds, you lose.
Survive all 3 levels. 

## How to Run
Built with Processing. 
Processing Version 4.0.1 (though any version works).
Main Sketch in SpaceGame.pde
Required Libraries: Simply processing.sound
To open and run project, click the triangle, play button. 

## Powerups:
There are THREE power-ups
1. +5 Health
2. +1 Laser Speed
3. +1 Laser
They will spawn every 5 to 15 seconds.

## Level Progression:
Rocks will fall faster.
Boss spawns at level 2.
Don't worry, the boss will return to the original spawn-point if it goes off-screen.

## Comments:

Yes, you lose 3 points for letting it go out-of-bounds.
